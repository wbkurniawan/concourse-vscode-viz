# Concourse Pipeline Visualizer for VS Code

A VS Code extension for previewing Concourse CI pipeline files.

## Features

- Live preview of Concourse pipeline YAML files
- Interactive visualization with D3.js
- Pan and zoom controls
- Syntax highlighting for pipeline elements
- Updates in real-time as you edit

## Requirements

- VS Code 1.60.0 or higher

## Usage

1. Open a Concourse pipeline YAML file in VS Code
2. Run the command "Show Concourse Pipeline Preview" from the Command Palette (Ctrl+Shift+P or Cmd+Shift+P)
3. The preview will open in a side panel and update as you edit

## Extension Settings

No configuration settings are available at this time.

## Known Issues

- Large pipeline files might affect performance
- Some complex Concourse pipeline features may not be fully supported
